# Proyecto 1 – Escenario 3  
**Conceptos Fundamentales de Programación**

## 🎯 Objetivo General  
Desarrollar un programa en **Java** que permita generar archivos de información de **vendedores**, **productos** y **ventas** de manera automatizada.  
Este proyecto busca fortalecer habilidades en programación orientada a objetos, manejo de archivos y generación de datos de prueba aplicables a proyectos reales.

---

## 📂 Estructura del Proyecto  
- `GenerateInfoFiles.java` → Clase que contiene los métodos para generar los archivos de información.  
- `Main.java` → Clase principal que ejecuta el programa.  
- `/output` → Carpeta donde se almacenan los archivos generados:  
  - `vendedores.txt`  
  - `productos.txt`  
  - `ventas.txt`
