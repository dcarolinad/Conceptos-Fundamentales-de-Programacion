# Proyecto Final – Conceptos Fundamentales de Programación

##  Descripción

Este proyecto tiene como objetivo simular el manejo de información de ventas realizadas por vendedores. La idea principal es generar archivos planos que contengan datos de ventas, productos y vendedores, los cuales serán utilizados como entrada para un programa que organizará y procesará dicha información.

---

## Estructura del Proyecto

- `GenerateInfoFiles.java`: Clase encargada de generar los archivos de entrada con datos simulados.
- `Main.java`: Clase principal que se usará para procesar los archivos generados (en desarrollo).
- `output/`: Carpeta que contiene los archivos generados:
  - `vendedores.txt`: Información básica de los vendedores.
  - `productos.txt`: Lista de productos disponibles.
  - Archivos individuales por vendedor con sus ventas.

---

## Ejecución

1. Abrir el proyecto en Eclipse.
2. Ejecutar la clase `GenerateInfoFiles`.
3. Verificar que se generen los archivos en la carpeta `output`.
